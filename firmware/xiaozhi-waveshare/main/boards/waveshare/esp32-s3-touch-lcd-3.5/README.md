## 小智光球与竖屏切页（CarCYD 功能版）

小智页使用用户提供的 ESP32S3_LVGL_Canvas_Orb 彩色光球，保留 MIT 许可于 `LICENSE-Orb`。
复用现有 LVGL 显示实例，不采用独立工程的屏幕初始化、GPIO 或模拟语音演示。
128×128 RGB565 画布使用 32768 字节 PSRAM，目标约 31 FPS（32ms，与 16ms 显示刷新周期对齐），离开小智页暂停绘制。
待机、聆听、思考、说话逐帧跟随设备状态；输入和播放 PCM 按 10ms 窗口提取去直流 RMS 音量。
音量采用 35ms 起振 / 140ms 回落，状态形态约 180ms 平滑过渡；动画相位连续，避免切换跳变。
仅在本板音频类中观察 PCM，不修改采样数据、不新增音频队列、I2S 写入或音频锁。
竖屏时光球在上、聊天在下；横屏时光球在左、聊天在右。独立布局和裁剪保证互不遮挡。
照片按聊天区域的可用尺寸缩放，聊天记录保留原有滚动。中文完整字库不变。
旧表情控件留在原有非活动屏幕，不再放到光球面板上。

“设置 → 显示 → 竖屏进入小智”默认开启。横屏转竖屏时进入小智，转回横屏时回到原仪表页面。
关闭后只旋转排版，仍可点击顶部“小智”手动进入。配网页面不会因自动切页被覆盖。
设置版本升到 2，追加字段在原 40 字节之后，旧参数保持，新开关默认开启，状态保存到 NVS。
原有 480×320 / 320×480 原生分辨率、80MHz SPI、PSRAM DMA、音频、相机与触摸设置保持。
